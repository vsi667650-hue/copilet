MINEGUARD — AI-Powered Predictive Rockfall Monitoring & Early Warning System
ROLE

You are a senior full-stack engineer, AI/ML engineer, IoT engineer, UI/UX designer, database engineer, and DevOps engineer.

Build a complete, runnable MVP called MINEGUARD for an open-pit mine safety monitoring system.

Do not create only a UI mockup.

Build a functional end-to-end MVP with:

Frontend + Backend + Database + ML Risk Engine + MQTT + ESP32 integration + Alert Engine + realistic demo/simulation mode.

The application must be clean, modular, responsive, easy to run locally in VS Code, and suitable for a hackathon demonstration.

1. PROJECT OBJECTIVE

MINEGUARD is an AI-powered predictive rockfall monitoring and early-warning platform.

The system should:

Collect environmental and slope-related sensor data.
Receive data from ESP32 through MQTT.
Store sensor readings in PostgreSQL.
Process sensor data.
Send features to an ML model.
Generate a prototype risk score from 0–100.
Classify the condition as:
SAFE
WARNING
CRITICAL
Display the result in a professional dashboard.
Identify the affected mine zone.
Generate an alert when risk becomes critical.
Send a physical alert to an ESP32 buzzer/LED when hardware is connected.
Provide a simulation mode so the entire MVP can be demonstrated without physical hardware.

IMPORTANT:

This is a prototype/hackathon system.

Do NOT claim that the risk thresholds are certified mining safety standards.

Clearly label prototype risk thresholds and recommended actions as demonstration logic requiring field validation before real-world deployment.
